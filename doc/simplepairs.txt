*simplepairs.txt*  Auto pairs for Vim9

SimplePairs inserts (), [], {}, quotes and backticks, skips an existing closing
character, removes empty pairs with Backspace and expands paired delimiters on
Enter.

:SimplePairsEnable      Enable the current buffer.
:SimplePairsDisable     Disable the current buffer.
:SimplePairsToggle      Toggle the current buffer.
:SimplePairsHealth      Show current state.

Set g:simplepairs_default_mappings to zero before loading to keep mappings
under vimrc control.  The expression functions simplepairs#Open(), #Close(),
#Backspace() and #Enter() are public integration points.
